# Listful Thinking 0.2.0-rc.1

This candidate brings the September security/reliability repairs and focused workspace redesign together with the next three roadmap milestones.

- **Today & upcoming:** overdue work, today's items and the next seven calendar days across your own and shared active lists, with local timezone/DST handling and safe completion.
- **Archive and recovery:** pause lists, undo recent deletion/archive, and restore lists or items from persistent Trash. Archived lists stop reminders and collaborator access; old public links remain revoked after restoration.
- **Personal templates:** save reusable private blueprints and create independent fresh lists. Content and recurrence settings carry over; completion history, guest reservations, shares and old dates do not. Events require a new target date.
- **Clearer workspace:** responsive list navigation, Items/Sharing/List settings, separate Administration, guided forms, empty states, English/German labels and remembered preferences.
- **Reliability and security:** expiring single-use email recovery, session rotation/invalidation, clear SMTP failures, revision-checked item updates, bounded/recoverable imports, durable reminder deduplication, redacted auditing and verified SQLite backups.

## Upgrade

Back up the database before upgrading. Migrations V14 and V15 run automatically. Existing records remain active. To roll back, restore the previous image **and its matching database snapshot**; do not point an old image at the upgraded schema.

API clients must supply `If-Match: "<version>"` on item PUT. Deletion now moves records to Trash. There is no automatic Trash purge in this candidate. Template item dates must be set on the new instance before scheduling reminders. Existing Duplicate list keeps its exact-copy semantics.

## Candidate artifacts

The release includes a Linux amd64 Docker image archive, a runnable Java 17 application JAR with the frontend embedded, and SHA256SUMS. GitHub provides the tagged source archives. Configuration, database files and SMTP credentials are excluded.

```bash
sha256sum -c SHA256SUMS
gunzip -c listful-thinking-0.2.0-rc.1-linux-amd64.docker.tar.gz | docker load
```

Loaded image: `listful-thinking:v0.2.0-rc.1`. Configure environment and persistent storage following the [self-hosting handbook](../deployment/self-hosting-handbook.md). For other architectures, build the tagged source with Docker Compose.
