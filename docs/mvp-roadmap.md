# MVP Roadmap

## Phase 0: Scaffold

- Repository skeleton
- Spring Boot backend shell
- Vue frontend shell
- Single-container Docker build

## Phase 1: Persistence

- Flyway SQLite schema
- JPA entities and repositories

## Phase 2: Auth and settings

- Session auth
- First-user admin bootstrap
- Registration toggle
- Backend i18n

## Phase 3: Lists and items

- Owner-isolated list CRUD
- Item CRUD
- Internal sharing

## Phase 4: Public sharing

- Cryptographic share tokens
- Guest read endpoint
- Guest claim endpoint

## Phase 5: Scraping

- Jsoup metadata scraping
- Async URL-only item enrichment

## Phase 6: Reminders

- Notifications
- SMTP-or-in-app graceful fallback

## Phase 7: Frontend MVP

- Auth screens
- Dashboard
- List detail
- Type-specific forms
- Share page
- Admin/settings

## Phase 8: Release verification

- Docker smoke script
- README quickstart
- Security test matrix
