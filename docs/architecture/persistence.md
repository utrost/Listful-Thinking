# Persistence Architecture

## Database

Listful Thinking uses SQLite as a single-file database.

Default runtime path:

- `/app/data/listful-thinking.sqlite`

Local/dev override:

- `LISTFUL_DB_PATH` may point elsewhere.

## Schema management

Use Flyway migrations in:

- `backend/src/main/resources/db/migration/`

Do not rely on Hibernate auto-DDL for production schema changes.

## ID strategy

- Use UUIDs generated by the application.
- Store UUIDs as SQLite `TEXT`.
- API IDs are UUID strings.

## Timestamp strategy

Use one consistent timestamp representation across migrations/entities/API. Recommended:

- Java: `Instant`
- API: ISO-8601 string
- SQLite: `TEXT` storing ISO-8601 UTC

## Initial tables

- `users`
- `lists`
- `items`
- `settings`
- `list_shares`
- `notifications`

## Indexing principles

Index every authorization lookup path:

- lists by owner user ID.
- items by list ID.
- lists by share token.
- notifications by user/read state.
- list shares by user and list.

## Backup model

All mutable state must live under `/app/data`. A self-hoster can back up the SQLite file and any future files under the same directory.

For schema-changing deployments, copy the live SQLite database before replacing the container and test additive migrations on the copy when practical. The Alice Tailnet runbook documents the concrete backup and post-deploy migration verification flow.

## Current item responsibility columns

Migration `V12__add_item_responsibility_labels.sql` adds nullable item-level responsibility metadata:

- `owner_label`
- `assistant_labels`

These fields are free-text coordination labels. They are not foreign keys to users, do not create shares, and do not affect authorization. Access remains inherited from the parent list and its internal/public sharing rules.

## SQLite caveats

- Prefer explicit migrations over generated schema.
- Keep transactions short.
- Be careful with concurrent async scraper updates.
- Avoid database-server-specific SQL.
- Enable foreign keys if required by JDBC/connection settings.
