# Support

Listful Thinking is a community self-hosted project. For setup, upgrades, and restore steps, start with the [Self-Hosting Handbook](docs/deployment/self-hosting-handbook.md). The [public HTTPS guide](docs/deployment/public-self-hosting.md) covers internet-facing instances, and the [RC3 release page](https://github.com/utrost/Listful-Thinking/releases/tag/v0.2.0-rc.3) identifies the published image.

For a reproducible defect, use a [bug report](https://github.com/utrost/Listful-Thinking/issues/new?template=bug-report.yml). For a website that extracts the wrong details, use an [extraction report](https://github.com/utrost/Listful-Thinking/issues/new?template=website-extraction.yml). Ideas and user experience feedback belong in a [feature request](https://github.com/utrost/Listful-Thinking/issues/new?template=feature-request.yml). Check existing issues first.

Include the app version or image digest, browser, list type, expected result, actual result, and steps to reproduce. Share only public source URLs. Remove private list content, account details, guest links, setup codes, cookies, and tokens from screenshots and logs.

For a vulnerability or a way to access another person's data, follow [SECURITY.md](SECURITY.md) instead of opening a public issue. The project cannot operate, monitor, or back up your instance; keep your own verified backups.
